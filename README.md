# Мониторинг ресурсов

 
Скрипт периодически каждые 10 сек записывает в файл monitor.log информацию
 - о использовании оперативной памяти, 
 - места на подлюченных дисках, 
 - время работы без перезагрузки, 
 - кол-во активных пользователей,
 - нагрузку на процессор. 

При каждом запуске файл очищается, стираются старые записи. 
Завершение работы - любая клавиша.
